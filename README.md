# Sistema de Registro Anagráfico

Sistema web para la gestión de personas y direcciones.

## Tecnologías

- Python
- FastAPI
- Flask
- PostgreSQL
- SQLAlchemy
- Pydantic
- Docker
- Docker Compose

## Arquitectura

Flask actúa como servidor web y cliente HTTP.

FastAPI proporciona la API REST.

PostgreSQL almacena los datos.
